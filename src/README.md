# Conecta Mentes - Modelagem de Banco de Dados

Este repositório contém a documentação e a modelagem de banco de dados para a plataforma digital "Conecta Mentes", desenvolvida como Projeto Integrador. O sistema foi projetado para otimizar e gerenciar o agendamento de sessões de mentoria.

## Estrutura do Projeto
* **/modelagem:** Modelos Conceitual e Lógico desenvolvidos na ferramenta brModelo.
* **/documentacao:** Apresentação do projeto e documentação de requisitos.
* **/scripts:** Scripts SQL gerados a partir do modelo lógico.
